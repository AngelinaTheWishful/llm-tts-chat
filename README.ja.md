# LLM ロールプレイチャット + GPT-SoVITS TTS

**言語:** [中文](README.md) · [English](README.en.md)

Gradio ベースのロールプレイチャットアプリで、LLM（OpenAI 互換 API）と GPT-SoVITS 音声合成を統合しています。

> **v1.3.4 リリース**（2026-08-06）· [GitHub Releases](https://github.com/AngelinatheMellowWish/llm-tts-chat/releases)

## 機能概要

- **LLM ロールプレイチャット**：DeepSeek / OpenAI / 通義など OpenAI 互換 API、複数プロバイダのフェイルオーバー
- **GPT-SoVITS TTS 音声合成**：キャラクターごとの声色クローン、長文の分割合成、音量ノーマライズ
- **マルチセッション管理**：新規作成 / 切替 / 削除 / リネーム / エクスポート / インポート（zip）
- **キャラクターシステム**：JSON 設定 + ポートレート + 参照音声 + Lorebook 世界観ナレッジベース
- **キャラクターカードインポート**：TavernAI（PNG/JSON）、RisuAI、Chub、Character.AI カードを自動検出してインポート（アバター付き）
- **キャラクターチャット背景**（v1.3.1）：キャラクターフォルダに背景画像（`background.png` または `character.json` の `background` フィールド）を置くと、キャラクター選択時にチャット領域の背景が即座に切り替わります。PNG/JPG/JPEG/WebP/GIF（アニメーション対応）、≤200MB。オーバーレイの不透明度・配色を調整可能（ライト/ダーク自動 + 手動選択）、有効化スイッチ、編集パネルでのアップロードとプレビュー対応
- **モバイル対応**：≤900px で自動的に上下レイアウトへ切替
- **キャラクター編集**：WebUI フォーム編集（性格 / 口癖 / 背景 / CoT / Lorebook / アバター）
- **メッセージのお気に入り / 検索 / 統計**：スター付きお気に入り、セッション内検索、全体統計ダッシュボード
- **トレーニング結果管理**：GPT-SoVITS のトレーニング成果をワンクリックでパック/アーカイブ（`gsv_training/`）、中間素材のクリーンアップ、アーカイブ復元、トレーニング完了の自動検出、キャラクター音声の連携
- **長期記憶（RAG）**：キャラクター別/全体のメモリ保存、セッションを跨いでユーザーの好みや事実を記憶（ルール抽出 + 任意で LLM 抽出）
- **セッションのゴミ箱**：削除したセッションは復元可能、30 日ごとにクリーンアップを促す
- **詳細設定**：パフォーマンス / セッションタイムアウト / 通知音 / プロキシ をすべて設定可能。プロキシは環境変数として注入
- **サイドバー調整**：ドラッグで幅調整（200〜600px）、ワンクリックで折りたたみ/展開、幅と状態を保存
- **セッション別 LLM プロバイダ**：各セッションで使用プロバイダを個別指定可能
- **多言語 UI**：中文 / 日本語 / English をホットスイッチ
- **テーマ**：ライト / ダーク + カスタムカラー
- **挨拶フロー**：新規セッションでキャラクターの音声挨拶を自動再生
- **ワンクリック起動**：`go-llm-tts.bat` が GPT-SoVITS TTS API とチャットアプリを同時起動（自動検出、ポートスキップ、2 ウィンドウ）
- **エラーコード + ステップレポート**：システム全体のエラーコード（`[LLM-004]` 等）+ 実行ごとのレポート（`logs/startup_report_*` / `run_report_*`、テキスト + JSON の二重形式）
- **操作ガイド**：メイン UI / サイドバーの「❓」ヘルプボタン
- **再生成 / メッセージ編集**：🔄 最後の AI 返答を再生成（旧バージョン保持）；✏️ 最後の AI 返答を編集（バージョン履歴付き）
- **自動バックアップ**：起動時 + 定期（既定で 24 時間ごと）にセッション / キャラクター / メモリ / 設定を `backup/` へ、直近 3 件を保持

## 環境要件

- Windows 10/11
- GPT-SoVITS v2Pro（runtime Python 環境が設定済みであること）
- LLM API Key

## インストール手順

1. `install_deps.bat` を実行して依存関係をインストール（venv を作成）
2. GPT-SoVITS と `llm_tts_update` が**同じ親ディレクトリ**にあることを確認（ワンクリック起動が `GPT-SoVITS*` ディレクトリを自動検出）
3. `go-llm-tts.bat` を実行 — GPT-SoVITS TTS API（api_v2.py）+ チャットアプリを自動起動（2 ウィンドウ）
4. 初回起動時は設定ウィザードで GPT-SoVITS のパス、TTS API アドレス、LLM 設定を入力

> 注：`go-llm-tts.bat` は同じ階層の `GPT-SoVITS*` ディレクトリを自動検出して `api_v2.py` を起動します（9880 ポートが使用中ならスキップ）。TTS の読み込みは約 30〜90 秒かかり、アプリが先に開きます。起動手順とエラーコードは `logs/startup_report_*.txt` に記録されます。

## 使用方法

1. **設定ウィザード**：初回起動時に GPT-SoVITS のパス、TTS API アドレス、LLM プロバイダ（Base URL / API Key / モデル）を入力
2. **キャラクター選択**：左サイドバーのドロップダウンから選択、プリセットの音声モデルが自動適用
3. **新規セッション**：「新規セッション」をクリック、キャラクターの挨拶が自動再生
4. **チャット開始**：メッセージを入力して Enter で送信（Shift+Enter で改行）。返答は自動的に音声合成
5. **キャラクター編集**：左サイドバーの「キャラクター編集」パネルで性格 / 背景 / Lorebook を変更し、アバター（またはチャット背景）をアップロード
6. **ツール**：セッションのエクスポート/インポート、検索、統計ダッシュボード
7. **トレーニング管理**：サイドバーの「トレーニング管理」パネルで実験を選択してプレビュー/パックし、中間素材をクリーンアップ。アーカイブ復元時に GPT-SoVITS への書き戻しも選択可能。または `train_pack.bat`（list / pack / cleanup / restore / list-archives / detect）を使用
8. **UI 言語**：上部ドロップダウンで中 / 日 / 英を切替。ライト / ダークテーマの切替も可能

## よくある質問（FAQ）

- **TTS の音が出ない**：GPT-SoVITS が起動済みで、ステータスバーに「🟢 TTS API オンライン」と表示されることを確認。ワンクリック起動で api_v2.py が自動起動
- **API Key の安全性**：API Key は `config.json` に base64 エンコードで保存されます。このファイルを共有しないでください
- **長い返答が途切れる**：800 字を超える返答は自動的に分割合成されます
- **トレーニング後にディスク容量が大きい**：サイドバーの「トレーニング管理」パネル、または `train_pack.bat pack <実験名> --cleanup` でパックして中間素材をクリーンアップ（パック検証後にのみ削除）
- **エラーコード付きのエラー**：UI のエラーは `[LLM-004] 利用可能な LLM プロバイダがありません` のような形式。コードで原因を特定できます。`logs/error.log` と `logs/run_report_*.txt` に完全な手順とコードが記録されます
